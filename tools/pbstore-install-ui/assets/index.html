PB Installer

Puts apps from the PB Store catalog on a PocketBook InkPad One that is connected as USB storage. PB Store is unofficial: it is not made, endorsed or supported by PocketBook.

1. Choose the reader

Connect the reader with the USB cable and set USB storage mode on its screen. Then choose it here.

Choose a folder by hand

For a reader that is not found, or a copy of a reader on this computer.

    2. Apps

    Install a package from this computer

    Such a package is not from the catalog and not signed by the maintainer. It is checked by the same rules.
