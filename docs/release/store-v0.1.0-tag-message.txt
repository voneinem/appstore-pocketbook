PB Store 0.1.0 for the PocketBook InkPad One

The first release of PB Store, the app on the reader that shows the signed
catalog of apps from this project and installs, updates, removes, adopts and
repairs them. It makes no network call until you tap, and switches Wi-Fi on
only for Refresh, Install and Update, and off again afterwards.
