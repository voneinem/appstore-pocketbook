PB Store 0.2.0 for the PocketBook InkPad One

Apps that have an update are now easy to see: a black "Update available" badge,
a filled icon, a place at the top of the list, and a banner on the first screen
that counts them. Update all asks once for the whole run and then updates the
apps one after the other.
