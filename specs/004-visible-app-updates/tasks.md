# Tasks: Visible App Updates

**Input**: Design documents from `/specs/004-visible-app-updates/`

**Prerequisites**: plan.md, spec.md (with the clarifications of 2026-11-01), research.md, data-model.md, contracts/ui-update-visibility.md, quickstart.md, checklists/requirements.md

**Tests**: REQUIRED. Constitution Principle I (Test-First, non-negotiable). In every user-story phase the test tasks come first, are written before the code they cover, and MUST be run and **seen failing** (a compile error for a missing symbol counts) before the implementation tasks start; each test group ends with a task that builds and runs them and records why each fails. Every `tests/**/test_*.cpp` is its own executable (the CMake glob picks up a new file): build and run one at a time, for example `cmake --build build-host --target test_app_filter` then `ctest --test-dir build-host -R test_app_filter --output-on-failure`. Walks (`tests/walks/*.walk`, run by `scripts/ui-walk.sh`) are tests in the same sense. A test that only pins behaviour this feature leaves unchanged may pass at once; say so in the task's note.

**Organization**: Grouped by the spec's user stories. US1 (mark and order the updatable apps) and US2 (count, banner, one confirmation for Update all) are both P1; US2 is the larger half and is built second because it also touches the most files. US3 (the menu entry and the single update stay) is a P3 regression story.

## Format: `[ID] [P?] [Story] Description`

- **[P]**: can run in parallel (different files, no dependency on an unfinished task)
- All paths are relative to the repository root `/home/voneinem/Projekte/appstore-pocketbook`
- Reuse, do not copy: `tests/support/{store_rig,fake_reader,sample_app,package_fixtures,tree_compare,throwing_fs}.h`; `StoreService::update_all_queue()`, `plan_action`, `execute_plan`, `StoreController::startAction/decline/confirm/updateAllSummary`
- The SDK location comes only from `$POCKETBOOK_SDK` or `-DSDK_PATH`; no path is written into any file
- Texts come from `bridge/strings/strings.tsv` (QML `qsTr("key")`, bridge `tr("key")`); `python3 scripts/extract-strings.py --check` must pass

## Path Conventions

One CMake project at the repository root (plan.md, Source Code): `core/store/` (library `pbstore_store`), `bridge/`, `qml/`, `tests/{store,bridge,walks,support}/`, `docs/`, `scripts/`. Qt Quick only in `bridge/ qml/ app/`; the Qt-free core and its tests never include Qt.
